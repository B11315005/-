對於一個連續函數f(x)，若f(x_1 )<0且f(x_2 )>0(f(x_1 )和f(x_2 )正負號相異)，則在x_1和x_2之間，必存在一個x的值，使得f(x)=0。牛頓法可以逼近此數值，作法是：先尋找x_1和x_2兩端點的中值x_3。然後，從x_1和x_2兩點之中，選取其中與x_3之f(x)正負號相異者，此被選取點與x_3會構成新的兩端點。對上述步驟進行迭代執行，就可以產生更多中點，不斷逼近該目標x的值。而連續函數f(x)=x-e^(-x)，此函數滿足f(0)<0且f(1)>0。所以，此函數可以套用牛頓法來逼近滿足f(x)=0的x值，其中x_1=0且x_2=1。請以實作程式，以尋找f(x)≅0的近似解。
提示：
在 (low, high)區間尋找解x, 初始low=0, high=1
    計算中點 middle = (low + high) / 2
若Math.abs(f[middle]) < threshold) 則結束
    若 (f(middle) < 0) 繼續搜尋(middle, high)區間
	否則 繼續搜尋(low, middle)區間
-------------------------------------------------------------------------------------------------
## 作業目的
找到連續函數中，f(x)≅0的近似解。

## 計算方法
透過(low + high) / 2 找到中間的點，還有透過公式 f(x) =  middle - Math.exp(-middle);算出中點的高度，如果高度離 0 的距離小於容許誤差，就印出X的位置

## 程式設定
初始範圍：0 到 1
容許誤差：0.0001

## 執行結果
x=0.567138671875
